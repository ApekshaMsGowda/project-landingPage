# TechNova Landing Page

A simple landing page built as part of The Odin Project curriculum.

## About

This project is a practice landing page created to improve my HTML and CSS skills. I built the layout from scratch and practiced using Flexbox to arrange and align different sections of the page.

## Features

- Header with navigation links
- Hero section with heading, description, image, and button
- Information section with four cards
- Quote/testimonial section
- Call-to-action section
- Footer

## Technologies Used

- HTML5
- CSS3
- Flexbox

## What I Learned

- Structuring a webpage using HTML
- Styling elements with CSS
- Using Flexbox for layouts
- Aligning and spacing elements
- Working with margins and padding
- Creating buttons and sections
- Using Git and GitHub to manage and publish my project
